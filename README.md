# java-racingcar-precourse

---

## 기능 요구사항

1. 사용자가 자동차 이름과 시행 횟수를 입력한다.
2. 각 자동차는 0~9까지의 난수를 생성한다.
3. 자동차별 난수가 4 이상이면 전진한다.
4. 시행 횟수만큼 진행 후, 가장 멀리 전진한 자동차를 우승자로 판별한다.
5. 우승자는 여러 명일 수 있으며, 그 경우 쉼표로 구분한다.
6. 예외 발생 시 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

---

## 예외 처리 기능

### 자동차 이름 입력
- 자동차 이름이 5글자를 초과할 경우
- 이름 구분자(,)가 없는 경우
- `null` 값 또는 잘못된 값이 입력될 경우

### 시행 횟수 입력
- 시행 횟수가 숫자가 아닌 다른 형식일 경우
- 정수가 아닌 수가 입력된 경우
- `null` 값 또는 잘못된 값이 입력될 경우
